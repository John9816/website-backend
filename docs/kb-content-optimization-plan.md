# 知识库和内容工厂生产级优化方案

## 📊 当前状态评估

### 知识库（Knowledge Base）
**现有功能：**
- ✅ 空间管理（KbSpace）- 基础CRUD
- ✅ 实体和Repository已实现
- ❌ 缺少文档管理（KbDocument）
- ❌ 缺少内容存储和检索
- ❌ 缺少向量搜索能力
- ❌ 缺少分享和权限管理

**问题：**
1. 一个用户只能创建一个空间（业务限制过严）
2. 没有文档上传和管理功能
3. 没有富文本编辑器集成
4. 缺少全文搜索

### 内容工厂（Content Factory）
**现有功能：**
- ✅ 文章生成（AI驱动）
- ✅ 热点选题
- ✅ 微信草稿箱对接
- ✅ 质量评分系统
- ✅ 图片生成集成
- ❌ 缺少定时任务
- ❌ 缺少批量管理
- ❌ 缺少模板系统
- ❌ 前端界面不完善

**问题：**
1. 没有content_article表的创建脚本
2. 缺少自动化调度
3. 图片生成没有队列管理
4. 没有草稿回收站
5. 缺少版本历史

## 🔧 详细优化方案

### 一、数据库优化

#### 1.1 创建缺失的表
```sql
-- content_article 表（如果不存在）
-- content_automation 表（自动化任务）
-- content_template 表（文章模板）
-- kb_document 表（知识库文档）
-- kb_document_share 表（文档分享）
```

#### 1.2 优化索引
- content_article: (user_id, status, updated_at)
- kb_document: (space_id, user_id, title)
- 全文搜索索引

### 二、知识库功能增强

#### 2.1 文档管理
- 创建/编辑/删除文档
- Markdown编辑器
- 富文本支持
- 文档分类和标签
- 文档版本历史

#### 2.2 搜索功能
- 全文搜索
- 标签搜索
- 高级筛选

#### 2.3 分享和协作
- 文档分享链接
- 访问权限控制
- 协作编辑（后期）

### 三、内容工厂功能增强

#### 3.1 模板系统
- 预设文章模板
- 自定义模板
- 模板市场

#### 3.2 批量操作
- 批量生成
- 批量发布
- 批量删除

#### 3.3 自动化调度
- 定时生成任务
- 定时发布任务
- 失败重试机制

#### 3.4 草稿管理
- 草稿箱
- 回收站
- 版本历史
- 草稿恢复

### 四、性能优化

#### 4.1 缓存策略
- Redis缓存热点数据
- 文章列表缓存
- 模板缓存

#### 4.2 异步处理
- 图片生成队列
- 文章生成队列
- 发布队列

#### 4.3 限流和降级
- API限流
- AI调用限流
- 降级策略

### 五、前端优化

#### 5.1 知识库界面
- 空间列表页
- 文档列表页
- 文档编辑器（Markdown + 富文本）

#### 5.3 体验优化

## 🚀 技术选型

### 后端
- Spring Boot 2.7+
- MySQL 8.0
- Redis 6.0+
- Caffeine Cache
- Spring Task Scheduler
- WebSocket (实时通知)

### 前端
- Vue 3
- Element Plus
- Markdown编辑器: vditor / cherry-markdown
- 富文本编辑器: tiptap / wangEditor
- 图表: ECharts

### AI服务
- 文章生成: MiMo v2.5 Pro
- 图片生成: WisArt / Stable Diffusion
- 搜索增强: RAG
