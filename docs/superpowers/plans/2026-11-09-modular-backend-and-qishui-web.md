# 黑源网页接入与后端模块化实施计划

用户要求：不使用子代理；优先完成 `/Users/wangweijie/projects/vs/website` 音乐项目黑源接入并部署、推送；后端架构、接口与性能优化不得改变现有功能。

执行方式：由当前会话顺序实施、自审、测试及发布。继续使用两个现有开发分支。前端开始时存在的下载镜像/部署文档修改保留，不纳入本次代码提交。

## 设计与兼容边界

- 保持单进程模块化后端，适合现有 2 核 ECS。按业务领域组织代码及依赖，不引入服务拆分、网络跳转或额外中间件。
- 现有 HTTP 路径、请求参数、响应字段、错误码、认证/会员/归属逻辑以及数据库数据语义均保持不变。
- 汽水网页复用现有搜索、歌单、收藏、播放及歌词流程；来源能力集中维护，未支持能力不展示为可用入口。
- 个人扫码在独立组件中完成；关闭窗口、切换账号或卸载时取消轮询，旧响应不能覆盖新会话。个人授权与解析凭据保持分离。
- 先建立接口及性能基线，再拆分职责，针对可验证瓶颈优化；不以缩短代码或移动文件充当性能提升。
- 发布使用版本目录、哈希校验、原子切换、健康检查及失败回滚；保留线上环境、持久数据、下载镜像和现有服务配置。
