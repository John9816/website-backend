# TuneFreeNext 4.3.5 能力对齐

目标：补齐已通过发布包及公开接口确认的能力，单 agent 完成、验证、推送、部署。

1. 汽水搜索建议：官方 `/search/sug/`，公共 catalog token，关键词验证、限量去重、短缓存；前端防抖、取消过时请求、键盘选择。
2. 分享歌单：官方站点白名单、逐跳验证、有限响应与超时；解析 H5 `_ROUTER_DATA.loaderData.playlist_page`；保留 `share:<id>` 来源用于同步；导入公开可用音轨，并说明视频/不可用项不在导入范围。
3. TTML：已确认 `https://lyrics.sayqz.com/v1/ttml/{wy|qq}/{id}`，仅网易/QQ。独立请求，不阻塞播放；超时/未收录/无效 XML 回退原歌词。支持逐字、翻译、罗马音，以及当前歌曲的本地 TTML/LRC 导入。限制大小、节点、深度，拒绝 DTD/entity。
4. 系统媒体/蓝牙歌词：Media Session 元数据、播放控制与位置；可选同步当前歌词为系统标题；关闭或切歌恢复曲目信息。浏览器功能检测，不能承诺所有车机显示。
5. 测试官方请求契约、缓存、边界、过时歌词隔离、桌面/移动布局；保留原播放和用户隔离。
6. 推送两仓库；以已提交版本构建组合发布，排除前端已有独立部署改动；备份、版本目录切换、健康检查与失败回滚。
